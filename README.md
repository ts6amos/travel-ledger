# 旅費記帳

純前端 PWA，不需要後端。資料存在瀏覽器（localStorage），沒網路也能記帳。

## 使用
- **電腦**：雙擊 `啟動.bat`（需要 Python），會自動開啟 http://localhost:5173。
  也可以直接雙擊 `index.html`，但這樣不會啟用離線快取（Service Worker 只在 http/https 運作）。
- **手機**：要用 HTTPS 網址才能「加入主畫面」並離線使用。把整個資料夾丟到任一靜態網站空間即可
  （GitHub Pages、Cloudflare Pages、Netlify 都免費，直接拖曳上傳）。

## 功能
| 功能 | 說明 |
|---|---|
| 匯率換算 | 自動抓即時匯率（ExchangeRate-API，備援 fawazahmed0），離線沿用上次匯率；可對每個外幣自訂匯率；有快速換算與常用金額對照表 |
| 每筆記帳鎖定匯率 | 記帳當下的匯率會存進該筆，之後匯率變動不影響舊帳；每筆都可手動改匯率（對應信用卡帳單） |
| 分類記帳 | 9 個分類、3 種付款方式（現金／信用卡／行動支付） |
| 刷卡手續費 | 旅程預設 1.5%，每筆可改；現金與結帳幣別本身不收手續費 |
| 預算與警示 | 總預算、每日預算（留空＝總預算÷天數）；用到 80% 與超支時提醒，當日超支也會提醒 |
| 視覺化 | 總覽（日均、最高單日、預估總花費）、分類圓環圖、每日長條圖（含預算線）、付款方式比例、各幣別合計 |
| 多旅程 | 每趟旅程各自的幣別、日期、預算、手續費 |
| 匯出 | CSV（UTF-8 含 BOM，Excel 直接開啟不亂碼）、全部資料 JSON 備份與匯入 |

## 檔案
- `index.html` / `app.css` / `app.js`：App 本體
- `sw.js`、`manifest.webmanifest`、`icon.svg`：離線與安裝
- 更新程式後若畫面沒變，是 Service Worker 快取的關係：重新整理兩次，或把 `sw.js` 裡的 `CACHE` 版本號加 1。

## 預留給下一版
每筆花費已有 `payer` 欄位、旅程有 `people` 清單，之後做「多人分帳／結算」不需要改資料格式。
